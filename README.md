# micro-bit-RC-Car

## A simple micro:bit RC car prototype using the nRF5x family's built in radio

## ⚠️ WARNING: This code only works with micro:bit v1 ⚠️
> The micro:bit v2 utilizes the NRF52 MCU, while the library I use is designed for NRF51 MCUs only. The NRF51 and NRF52 are from the same NRF5x family, but we can't just assume the differences won't affect the code

## What's this?
This is a simple RC car example, utilizing the NRF51's built in radio. It's coded in Arduino. If you don't have Arduino IDE, there are prebuilt **.hex** binaries you can transfer to the micro:bit via **USB**.
